# ai-automation-portfolio
Automation and AI workflow projects including RPA, Python automation, and AI-powered data processing solutions.

- **Insurance Claim Processing Automation**  
  End-to-end RPA/AI solution using UiPath Document Understanding, custom LLM prompts for JSON risk analysis (potential issues, missing fields, confidence scores), programmatic validation, error handling (try-catch/email alerts), and automated Google Sheets reporting. Built with synthetic/fictional data to showcase intelligent workflow modernization in insurance.  
  [Explore Folder →](https://github.com/anthony-tipton-dev/ai-automation-portfolio/tree/main/insurance-claim-automation)
  
- **Weather-Based Sales & Staffing Automation**  
  Scheduled Zapier workflow pulls Miami forecast, uses Gemini for intelligent recommendations (product focus, staffing adjustments, promotional messages), and emails formatted summaries/alerts. Demonstrates no-code AI automation for operational efficiency.  
  [Details](https://github.com/anthony-tipton-dev/ai-automation-portfolio/tree/main/weather-decision-engine)
